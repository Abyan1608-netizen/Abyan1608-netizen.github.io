# Taman Bintang — portofolio dan e-book TI gratis

Web 3D (Next.js + React Three Fiber) berisi catatan belajar mahasiswa Teknik Informatika kelas karyawan.

## Menjalankan di Mac
```bash
npm install
npm run dev      # buka http://localhost:3000
npm run build    # hasil statis ada di folder out/
```

## Mengubah nama dan teks
Edit `site.config.ts`. Adegan 3D ada di `components/Scene.tsx`.

## Pasang online (gratis)
Cloudflare Pages: hubungkan repo GitHub, build command `npm run build`, output directory `out`.
