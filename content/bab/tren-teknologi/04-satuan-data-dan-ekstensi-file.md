Semua data di komputer, mulai dari teks sampai film, disimpan sebagai angka **0 dan 1**. Ukurannya dihitung dengan satuan khusus.

> **Setelah membaca bab ini, kamu bisa:** menyebutkan urutan satuan data, mengonversinya, dan mengenali jenis file dari ekstensinya.

## Satuan dasar

- **Bit** (*binary digit*) adalah satuan terkecil, bernilai **0 atau 1**.
- **Byte** adalah kumpulan **8 bit**.
- **Character (karakter)** adalah satu huruf, angka, atau simbol. Satu karakter umumnya memakai **1 byte** (misalnya huruf "A").

## Tangga satuan

Setiap tingkat bernilai **1024** kali tingkat sebelumnya (dalam hitungan biner komputer).

| Satuan | Singkatan | Nilai |
|---|---|---|
| Kilo Byte | KB | 1024 Byte |
| Mega Byte | MB | 1024 KB |
| Giga Byte | GB | 1024 MB |
| Tera Byte | TB | 1024 GB |
| Peta Byte | PB | 1024 TB |
| Exa Byte | EB | 1024 PB |
| Zeta Byte | ZB | 1024 EB |

Urutan dari kecil ke besar: **bit → byte → KB → MB → GB → TB → PB → EB → ZB**.

*Catatan: pabrik penyimpanan sering memakai hitungan desimal (1 KB = 1000 byte), itu sebabnya flashdisk 64 GB tampak sedikit lebih kecil di komputer.*

## Kilo Byte dan Kilo Bit

Daftar soal memuat "Kilo Byte" dua kali dan "Kilo Bit" satu kali.

- **Kilo Byte (KB)** = 1024 byte. Huruf B kapital.
- **Kilo Bit (Kb atau kbit)** = 1024 bit (atau 1000 bit untuk kecepatan jaringan). Huruf b kecil.

Bedanya penting: 1 byte = 8 bit, jadi 1 KB = 8 Kb. Kecepatan internet biasanya dalam bit (Mbps), ukuran file dalam byte (MB).

## 256, 512, dan 1024 Byte

Ketiganya adalah bilangan **pangkat dua**, karena komputer bekerja dengan biner:
- 256 Byte = 2⁸ byte
- 512 Byte = 2⁹ byte (ukuran satu sektor pada banyak disk)
- 1024 Byte = 2¹⁰ byte = **1 Kilo Byte**

## Contoh konversi

- 2 KB = 2 × 1024 = **2048 Byte**
- 1 MB = 1024 × 1024 = **1.048.576 Byte**
- 3 byte = 3 × 8 = **24 bit**
- 2048 MB = 2048 ÷ 1024 = **2 GB**

## Ekstensi file

**Ekstensi** adalah akhiran nama file setelah titik, yang memberi tahu jenis isinya.

| Ekstensi | Jenis | Dibuka dengan |
|---|---|---|
| **.mp3** | File **audio** (musik), terkompresi sehingga ukurannya kecil | Pemutar musik |
| **.docx** | Dokumen **Microsoft Word** (2007 ke atas). Versi lama: .doc | MS Word |
| **.xls** | **Spreadsheet** Microsoft Excel (versi lama). Versi baru: .xlsx | MS Excel |
| **.psd** | File **Adobe Photoshop**, menyimpan gambar beserta lapisan-lapisannya (*layer*) | Photoshop |

## Latihan singkat

1. 1 byte sama dengan berapa bit?
2. Berapa byte dalam 1 KB?
3. File .psd dibuka dengan aplikasi apa?

*Kunci: (1) 8 bit. (2) 1024 byte. (3) Adobe Photoshop.*
